Personal Expense Tracker

Project Overview

Personal Expense Tracker is a menu-driven application developed using C programming. It helps students manage their monthly budgets, record daily expenses, and monitor spending across different categories.

Features

- Set a monthly budget.
- Add multiple expenses.
- Categorize expenses into Food, Travel, Books, and Entertainment.
- View all recorded expenses.
- Calculate total spending and remaining budget.
- Display category-wise expenditure.
- Identify the highest expenditure category.
- Display warnings when the budget is exceeded.
- Validate invalid categories and non-positive expense amounts.

Technologies Used

- Programming Language: C
- IDE: Visual Studio Code
- Compiler: GCC

C Programming Concepts

- Variables and data types
- Arrays and strings
- Loops
- Conditional statements
- Switch-case
- Functions

How to Run

Compile the program:

"gcc expense_tracker.c -o expense_tracker.exe"

Run on Windows PowerShell:

".\expense_tracker.exe"

Program Menu

1. Set Monthly Budget
2. Add Expense
3. View All Expenses
4. View Expense Summary
5. Category-wise Report
6. Exit

Sample Result

Monthly Budget: Rs. 5000.00

Total Spending: Rs. 5500.00

Remaining Budget: Rs. -500.00

Budget Status: Exceeded

Highest Expenditure Category: Entertainment

Limitations

- Expense records are stored only while the program is running.
- The program supports up to 100 expense records.
- Some non-numeric inputs are not fully handled.

Future Improvements

- Permanent file storage
- Monthly expense history
- Edit and delete expenses
- Graphical user interface

Conclusion

The Personal Expense Tracker provides a simple way for students to monitor expenses, identify spending patterns, and manage monthly budgets.
